# Implementation Plan: Supabase Integration & Admin Panel

**Branch**: `feature/supabase-admin-panel` | **Date**: 2026-06-24 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-supabase-admin-panel/spec.md`

## Summary

Migrate the Instituto Movimenta site from in-memory API route stubs to a Supabase PostgreSQL backend, and build a protected admin panel at `/admin` for the team to view, filter, export, and delete form submissions. All four public forms gain LGPD consent checkboxes and honeypot spam protection. Server Actions replace the existing API route stubs. The admin panel uses Supabase Auth (email + password) for login, cookie-based sessions, and Row Level Security for data isolation.

## Technical Context

**Language/Version**: TypeScript 5.9 / Next.js 15.5 (App Router)

**Primary Dependencies**:

- `@supabase/ssr` — Supabase client for Next.js App Router (Server Components, Server Actions, Middleware, cookie handling)
- `@supabase/supabase-js` — Supabase base client (peer dep of `@supabase/ssr`)
- Existing: Zod 3.x, React Hook Form 7.x, shadcn/ui (new-york), Tailwind CSS v4, Lucide React

**Storage**: Supabase PostgreSQL — managed cloud; 4 tables (see `data-model.md`)

**Testing**: Vitest — unit tests co-located with source; covers schema validation and Server Action guard logic (honeypot, duplicate error mapping)

**Target Platform**: Vercel — Edge Middleware (auth guard) + Serverless Functions (Server Actions)

**Project Type**: Full-stack Next.js web application

**Performance Goals**:

- Public form confirmed to user in < 3 s (SC-001)
- Admin dashboard initial load < 3 s (SC-008)

**Constraints**:

- App Router only — Pages Router is prohibited
- No new `.css` files — Tailwind utilities + existing tokens in `globals.css`
- No `useState` for form state — React Hook Form exclusively
- Package manager: `bun` only (`bun add` / `bun remove`)
- LGPD: mandatory consent checkbox on all public forms (not stored, validates before insert)
- Out of scope: donation form, email notifications via Resend, rate limiting per IP

**Scale/Scope**: Small NGO — < 100 form submissions / week; ≤ 5 admin users; no horizontal scaling required
